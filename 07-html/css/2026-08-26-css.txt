css정리 스타일시트.
------------색------------
 <style type = "text/css">
        p { color : blue; }       --- p 태그 안의 글자들을 파란색으로 처리함.
 </style>

p=선택자
color=속성

<p>머리가 좋아지는 음식</p> //파랑


--------------------------특정 행 색 고르기------------------------
   #ctxt { color : blue; }     --- id명이 ctxt인 요소의 글자들을 파란색으로 처리함.
   .ctxt { color : blue; }     --- class명이 ctxt인 요소의 글자들을 파란색으로 처리함.	


  <p class = "ctxt">건강에 좋은 차</p>   		//파랑(ctxt class들 전부 파랑)- 작은영역에많이씀
  <p id = "ctxt">건강에 좋은 차</p>   		//파랑(ctxt 아이디들 전부 파랑)- 큰영역에많이씀
ㄱㄷㅈ골ㅇ노ㅕㅑㄹㅇ노ㅕㅑㅇㄴ로ㅕㅑ		//검정

-----------------body의 모든요소 -  전체선택자
* { color : blue; }
-------------------------------- li 아래에있는 p 요소 > 자식선택자------------
li > p { color : blue; } 
------------------------------------ hi 속 바로 다음 p 태그의 글자들을 파란색으로 처리함.>인접선택자-----
 h1 + p { color : blue; }         
----------------------------------
* { margin = 0}  ---모든요소의 바깥쪽여백을 0으로
	padding ---안쪽여백
-------------------------------------------
{background : 오렌지} ---배경오렌지
---------------------------------------------------
 h1[class] { color : blue; }           --- 두 hi 중 class 속성을 가진 '서울특별시'만 파란색으로 나타난다.
-------------------------------------------------------------------
 a { color : 까망}    --까망색표시
a:hover { color : 빨강 } --a태그에 마우스 대면 빨강으로 변함
